Features

Everything a file manager should do, from the keyboard

Built for people who move a lot of files: on their disk, in archives, on servers and in the cloud.

Two panels, tabs, up to four

Copy, move and compare between the panels with one key. Folder tabs, workspaces, a side split in two, history, a Hotlist and the folders you use most.

Command palette

Any command, folder, Hotlist entry or saved connection, found by typing a few letters. Ctrl+Shift+P

Compare and merge

Files side by side, edited in place; copy differences across, merge three files, make and apply patches, hex, pictures and documents too.

Archives and packages

zip, 7z, rar, tar, iso, virtual disks, .deb, .rpm, .msi and container images open like folders.

Background jobs and undo

Copies run in a queue with pause, speed limit and verification. Ctrl+Z undoes copy, move, rename and delete to the Recycle Bin, after telling you what it will do.

Find, rename, synchronize, measure

Find files by name and content, also inside Office files; rename hundreds of files with a preview; make two folders equal; see where the space went in a treemap; find duplicates.

Macros and scripts

Record the commands you run as a command of your own; write commands, columns and file systems in JavaScript.

Viewer and editor

Text with syntax colors, hex, pictures with camera RAW, audio and video, Markdown, PDF and Office documents without Office; an editor that keeps the file's encoding.

Plugins

Git, Docker, Kubernetes, SQLite, rclone, GitHub and GitLab, virtual disks, packages and more viewers ship with it; write your own in C#.

Safe by default

Settings backups you can restore, a master password for saved secrets, pairing codes for PC link, and a retry with administrator rights when an operation needs it.

Tour

Look around the way you would in the app

Move the cursor with ↑ ↓ or click a line; the right side shows it, like Quick View does.

Connections

Servers, clouds and devices in the same panels

A remote folder is a folder: copy to it with F5, view with F3, compare it with a local one.

File servers

FTP, FTPS, SFTP, SCP, WebDAV, SMB, web server folder listings

Object storage

Amazon S3 and compatible stores, Azure Blob Storage, Azure Files

Cloud drives

Google Drive, OneDrive, Dropbox, Box, rclone remotes

Containers and code

Docker containers and volumes, Kubernetes pods, Git history, GitHub and GitLab repositories

Devices

Android phones over ADB, phones and cameras over MTP, another PC over a cable with PC link

Sessions

Remote desktop in a tab, VNC, SSH, Telnet, rsh and serial consoles in the built-in terminal

Proxies (HTTP, SOCKS, SSH tunnel, PAC) for the whole program or one connection; saved passwords behind an optional master password; a log per connection.

Looks

Fits the system it runs on

Follows the system's light or dark mode, or takes a macOS or Ubuntu look. Three icon packs, six languages built in, your own themes, and every shortcut and button can be changed.

Download

Self-contained, nothing else to install

Every package carries what it needs. The packages are on the latest release.

Windows

A setup program that installs for your user without administrator rights, a zip, and a portable zip that keeps its settings next to it.
