# NextCommander 26.11.446

The first release of NextCommander: a dual-pane file manager for Windows, Linux and macOS that you drive from the
keyboard. Two file panels side by side, a menu bar, a button bar, a command line and the F3 … F8 keys at the bottom.

## Download

| System | Package | How to start |
|---|---|---|
| Windows (x64, Arm64) | `-setup.exe` | Installs for your user without administrator rights; adds a Start menu entry and, if you choose, "Open in NextCommander" in Explorer. |
| | `.zip` | Unpack anywhere and start `NextCommander.exe`. |
| | portable `.zip` | Keeps its settings in its own folder, for a USB stick. |
| Linux (x64, Arm64) | `.deb` | `sudo apt install ./NextCommander-26.11.446-linux-x64.deb` |
| | `.rpm` | `sudo dnf install ./NextCommander-26.11.446-linux-x64.rpm` |
| | `.tar.gz` | Unpack and start `NextCommander`. |
| macOS (Apple silicon, Intel) | `.app` in a zip or disk image | Drag it to Applications. An unsigned copy may first need *System Settings > Privacy & Security > Open Anyway*. |

Every package is self-contained: nothing else needs to be installed. 7-Zip (writing 7z archives), VLC (audio and
video in the viewer) and Everything, plocate or Spotlight (faster search) turn on extra features when they are there.

## What it does

**Panels and files**
- Two panels with folder tabs; a side can be split into two panels, up to four in all.
- Copy, move, rename and delete in the background with a queue, pause, a speed limit and verification.
- **Undo (Ctrl+Z)** for copy, move, rename, multi-rename, new folder and deleting to the Recycle Bin. It tells you
  what it will do before it does it.
- **Command palette (Ctrl+Shift+P)**: any command, folder, Hotlist entry or saved connection, found by typing.
- **Quick View (Ctrl+Q)** in place of the other panel, or below or right of the file list.
- Saved workspaces, tags with color labels, saved searches that open like folders, and rules that move arriving
  files or synchronize folders every night.
- Permissions: Unix mode, owner and group (also over SFTP), and Windows access lists, in one window.
- Operations that fail for missing rights can run again as administrator through the system's own dialog.

**Viewing and comparing**
- The viewer (F3): text with syntax colors, hex, pictures including camera RAW, PDF pages, Word, Excel and PowerPoint
  without Office, Markdown, e-mails, e-books, notebooks, certificates, fonts, and photo metadata with the GPS position.
- **Compare and merge**: edit both files in place, copy differences across, merge three files, compare binary files
  as hex, documents as text and pictures side by side; make and apply patches; HTML reports.
- Synchronize directories is also the folder compare, by date, size or content, with presets and an export.
- Find files, Multi-Rename Tool, duplicate files, folder sizes with a treemap, checksums, split and combine.

**Archives and containers**
- zip, 7z, rar, tar and other archives, .iso images, virtual machine disks (.vhd, .vhdx, .vmdk, .vdi, .dmg) and
  packages (.deb, .rpm, .cab, .msi, container images) open like folders.
- Pack to zip, tar, iso and 7z, split or self-extracting; mount disc images.

**Connections**
- FTP, FTPS, SFTP, SCP, WebDAV, SMB, Amazon S3 and compatible stores, Azure Blob and Files, Google Drive, OneDrive,
  Dropbox, Box and rclone remotes, in the same panels as local files.
- Docker containers and volumes, Kubernetes pods, Git history, GitHub and GitLab repositories.
- Android phones over ADB, phones and cameras over MTP, and PC link: two computers over a cable or the network.
- Remote desktop in a tab, VNC, and SSH, Telnet, rsh and serial consoles in the built-in terminal, with SSH tunnels,
  proxies and a connection manager. Sites can be imported from FileZilla, WinSCP, PuTTY and MobaXterm.

**Your way**
- Follows the system's light or dark mode, or a Dark, macOS or Ubuntu look; three icon packs.
- English, Turkish, German, Spanish, French and Chinese built in; add a language with one file.
- Every shortcut and button can be changed; macros and JavaScript add commands, columns and file systems; plugins.
- The last seven settings files are kept, and any of them can be restored.

## Known limits

- SSH agent forwarding is not available.
- Some parts are tested against test servers but not yet against every real service: Box, Azure Files, AWS SSO,
  Entra ID sign-in, remote desktop in a tab on Linux, and phones over MTP on macOS. Please report what you find.
- On macOS, a copy that is not signed by a registered developer has to be allowed once in the system settings.
