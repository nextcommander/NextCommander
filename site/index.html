Two panels.
Every file within a few keys.

NextCommander is a dual-pane file manager for Windows, Linux and macOS. Copy between the panels with one key, open archives and servers like folders, and keep your hands on the keyboard the whole time.

Look around the way you would in the app

Move the cursor with ↑ ↓ or click a line; the right side shows it, like Quick View does.

NameKey

Servers, clouds and devices in the same panels

A remote folder is a folder: copy to it with F5, view with F3, compare it with a local one. Saved connections live in a connection manager with the options of each type.

File servers
FTP, FTPS, SFTP, SCP, WebDAV, SMB, web server folder listings
Object storage
Amazon S3 and compatible stores, Azure Blob Storage, Azure Files
Cloud drives
Google Drive, OneDrive, Dropbox, Box, rclone remotes
Containers and code
Docker containers and volumes, Kubernetes pods, Git history, GitHub and GitLab repositories
Devices
Android phones over ADB, phones and cameras over MTP, another PC over a cable with PC link
Sessions
Remote desktop in a tab, VNC, SSH, Telnet, rsh and serial consoles in the built-in terminal

Proxies (HTTP, SOCKS, SSH tunnel, PAC) for the whole program or one connection; saved passwords behind an optional master password.

Fits the system it runs on

Follows the system's light or dark mode, or takes a macOS or Ubuntu look. Three icon packs, six languages built in, and every shortcut and button can be changed.

Download

Every package is self-contained: nothing else needs to be installed. The packages are on the Releases page.

Windows

A setup program that installs for your user without administrator rights, a zip, and a portable zip that keeps its settings next to it, for a USB stick.

Linux

A .deb for Debian, Ubuntu and Mint, an .rpm for Fedora, RHEL and openSUSE, and a .tar.gz.

sudo apt install ./NextCommander-<version>-linux-x64.deb

macOS

NextCommander.app in a zip or a disk image. Drag it to Applications. An unsigned copy may first need Privacy & Security > Open Anyway.

Optional helpers turn on extra features when they are installed: 7-Zip writes 7z archives, VLC plays audio and video in the viewer, Everything, plocate or Spotlight speed up searches.
